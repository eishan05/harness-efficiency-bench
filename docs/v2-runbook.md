# v2 runbook

How v2 runs are set up and launched. The plan and its reasoning are in [PLAN-v2.md](PLAN-v2.md).

## What is different from v1

- **One model for every harness.** OpenCode Go serves the model; the default is `deepseek-v4.1-flash`.
- **One measurement path.** Every harness talks to the bench's usage proxy, and the proxy talks to Go. The proxy:
  - holds the real key (`OPENCODE_GO_API_KEY`); containers only get the placeholder `BENCH_API_KEY=proxy-holds-the-key`;
  - replaces whatever credentials the harness sends with the real key;
  - adds one `x-opencode-session` per task run (Go requires a stable session id);
  - records per-call usage, normalized across the OpenAI, Anthropic and Gemini formats (`normalized_usage` in `.harness-usage-proxy.jsonl`);
  - listens on the `docker0` bridge address, not on every interface.
- **Manifests** are in `examples/harnesses/v2/`, generated by `scripts/gen_v2_manifests.py`. Edit the script, not the YAML.
- **agy** only accepts models from its own catalog. It is told to use `gemini-3.8-flash-medium` (`AGY_MODEL`), and the proxy rewrites each request to the model under test (`force_model`). Each rewritten call keeps the original name as `requested_model`.

Go's format endpoints, checked 2026-11-20 (all three share one prompt cache):

| Format | Upstream | Used by |
|---|---|---|
| OpenAI chat and Responses | `https://opencode.ai/inference/go/openai/v1` | most harnesses; Codex uses Responses |
| Anthropic messages | `https://opencode.ai/inference/go/anthropic` | Claude Code |
| Gemini | `https://opencode.ai/inference/go/google` | agy |

## Droplet

Disposable. Everything below runs from a workstation with `doctl` authenticated.

```bash
# 1. droplet + firewall (SSH from one address only; no web server anywhere)
doctl compute droplet create harness-bench-v2 --region tor1 --size s-8vcpu-16gb \
  --image ubuntu-24-04-x64 --ssh-keys <key-id> --tag-names harness-bench --wait
doctl compute firewall create --name harness-bench-fw --tag-names harness-bench \
  --inbound-rules "protocol:tcp,ports:22,address:<your-ip>/32" \
  --outbound-rules "protocol:tcp,ports:all,address:0.0.0.0/0,address:::/0 protocol:udp,ports:all,address:0.0.0.0/0,address:::/0"

# 2. setup: Docker, Python + PyYAML, container firewall, bench user (uid 1000)
ssh root@IP 'bash -s' < scripts/droplet/bootstrap.sh

# 3. code and key (the key file is readable by the bench user only)
scripts/droplet/push.sh root@IP
echo "OPENCODE_GO_API_KEY=..." | ssh root@IP 'umask 077; cat > /opt/bench/secrets.env; chown bench:bench /opt/bench/secrets.env'

# 4. images, tagged with the Dockerfiles' pinned versions
ssh root@IP 'cd /opt/bench/hb && scripts/droplet/build-images.sh'
```

Container firewall (`bootstrap.sh`): containers can't reach the droplet's sshd, the DO VPC (10/8, which includes DO's resolver, so Docker uses 1.1.1.1 and 8.8.8.8), the metadata service or 100.64/10. They can reach the proxy on the bridge and the internet.

## Runs

Run as the `bench` user. Claude Code refuses `--dangerously-skip-permissions` as root, and the bench starts containers as the calling user.

```bash
ssh root@IP
cd /opt/bench/hb
sudo -u bench -H scripts/v2/run.sh smoke smoke1                      # toy task, every harness
sudo -u bench -H JOBS=3 scripts/v2/run.sh suite r1                   # 12 score-facing tasks
sudo -u bench -H JOBS=3 scripts/v2/run.sh suite r1 pi-go crush-go    # some harnesses
sudo -u bench python3 scripts/v2/summarize.py runs/v2/r1
python3 scripts/v2/pool.py runs/v2/r1 runs/v2/r2 runs/v2/r3 --csv runs/v2/pooled-r1-r3.csv
```

`pool.py` pools repeats per harness: median and range of tokens per solved task, cache-discounted tokens, startup tax, and cache behavior from the per-call proxy records (cached share after the first call, on the first call, and turn-to-turn prefix reuse).

- Results go to `runs/v2/<run>/<harness-id>/`, with logs and conditions (git commit, image IDs, model) in `runs/v2/<run>/logs/`.
- A harness whose results already exist is skipped, so rerunning a command resumes a stopped run.
- Repeats are separate run names (`r1`, `r2`, `r3`).
- Go prices double on weekdays 01:00-04:00 and 06:00-10:00 UTC. Start long runs outside those hours.

`summarize.py` checks the Go setup per harness. Both of these columns should be clean:

- `sessions>1`: task runs whose calls carried more than one session id (should be 0);
- `requested`: model names a harness asked for that the proxy rewrote (expected only for agy).

## Teardown

Copy the results off, then destroy the droplet (a powered-off droplet is still billed):

```bash
rsync -az root@IP:/opt/bench/hb/runs/v2/ runs/v2/
doctl compute droplet delete harness-bench-v2
doctl compute firewall delete <firewall-id>
```
